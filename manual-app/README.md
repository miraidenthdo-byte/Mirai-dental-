# みらい歯科 院内マニュアルアプリ

パステルピンクを基調にした、スタッフ向けの院内マニュアルアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。

## 使い方

- `index.html` をブラウザ（Chrome / Safari）で開くだけで使えます。
- スマートフォン・タブレットでは、ホーム画面に追加するとアプリのように使えます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| カテゴリ別一覧 | 受付・会計 / 診療補助 / 滅菌・消毒 / 緊急時対応 / 開院・閉院 / 患者さま対応 / 器具・材料 / 院内ルール |
| 検索 | タイトル・手順・ポイント・キーワードをまとめて検索 |
| ステップチェック | 手順ごとにチェックでき、進み具合をバーで表示 |
| ポイント／注意 | 手順ごとにコツ（ピンク）・注意（コーラル）を表示 |
| お気に入り・最近見た | よく使うマニュアルにすぐアクセス |
| その場で編集 | マニュアル画面で「ロックを解除して編集」→ そのまま書き換え →「保存してロック」 |
| 編集ロック | 普段はロック中で書き換え不可。解除の確認（または暗証番号）を経てから編集できます |
| 作成・削除 | 下の「追加」から新規作成。削除は編集中の画面下から |
| 文字サイズ | 設定から「大きめ」に切り替え可能 |
| ダークモード | 端末の設定に合わせて自動切り替え |
| 書き出し／読み込み | データをコピーして別の端末へ移せます |

## 編集ロックについて

- マニュアルは普段**ロック中**で、誤って書き換えることはありません。
- 「ロックを解除して編集」を押し、確認画面で解除すると、その画面のまま文字を直せます。
- 「保存してロック」で保存と同時にロックに戻ります。「取り消す」で変更前に戻せます。
- 保存せずに他の画面へ移ろうとすると、確認が出ます。
- 設定（右上の歯車）で**4桁の暗証番号**を決めると、解除のときに入力が必要になります。
  ※ 誤操作を防ぐためのロックです。暗証番号はその端末にだけ保存されます。

## データの保存について

- 作成・編集したマニュアルは、**開いている端末のブラウザ内**に保存されます。
- 他の端末と共有したいときは、設定（右上の歯車）→「データの書き出し」でコピーし、
  もう一方の端末の「データの読み込み」に貼り付けてください。
- 初期のマニュアルはサンプルです。院内の手順・AEDの場所などに合わせて編集してください。
