# みらい歯科 院内マニュアルアプリ

パステルピンクを基調にした、スタッフ向けの院内マニュアルアプリです。
スタッフごとの進み具合を記録し、管理者がまとめて確認できます。
スタッフは自分専用のログインコードでログインし、退職したスタッフは管理者がすぐに利用停止できます。

## 2つの使い方

| | 体験モード | スプレッドシート版（スタッフ全員で使う） |
| --- | --- | --- |
| 開き方 | `index.html` をブラウザで開く | Google Apps Script のウェブアプリURLを開く |
| データの保存先 | その端末のブラウザの中だけ | Googleスプレッドシート（全員で共有） |
| スタッフ・進み具合 | サンプルが入っています（ログイン画面に体験用コードを表示） | 管理者が登録したスタッフの実際の記録 |

同じ `index.html` が、開き方によって自動で切り替わります。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| カテゴリ別一覧・検索 | タイトル・手順・ポイント・キーワードをまとめて検索 |
| ステップチェック | 手順ごとにチェック。全部チェックすると「完了」として記録 |
| ログイン | スタッフは6桁のログインコードでログイン。共用の端末は、使い終わったら右上の名前→「ログアウト」 |
| あなたの進み具合 | ホームとくわしい画面で、自分の完了率・要再確認を確認 |
| その場で編集＋ロック | 「ロックを解除して編集」→ 書き換え →「保存してロック」。補足は「声かけ例・ポイント・注意」を1つの手順にいくつでも付けられます |
| 再確認の依頼 | 編集時に「スタッフ全員に再確認してもらう」を選ぶと、完了済みの人が「要再確認」になります |
| 管理者ページ | スタッフ別・マニュアル別の進み具合、スタッフ登録・退職、セキュリティ、データ管理 |

## 管理者ページ

設定（右上の歯車）→「管理者ページを開く」、またはログイン画面の「管理者の方はこちら」。初回に管理者用の4桁の暗証番号を決めます。

- **スタッフ別**：全体の完了率、要再確認の件数、この7日間の完了数。スタッフを完了率の低い順に表示し、押すとその人のマニュアルごとの状況（完了日・途中のステップ数）が見られます。
- **マニュアル別**：完了した人が少ない順に表示。押すと、誰が完了／途中／未着手かが分かります。
- **スタッフ管理**：スタッフの追加（ログインコードを発行）、名前の変更、ログイン中の端末の確認、コードの再発行、退職の手続き、暗証番号、マニュアルの書き出し／読み込み。

進み具合の表示は次の4つです。

- **完了**：すべてのステップにチェックした（チェックをリセットしても完了の記録は残ります）
- **要再確認**：完了したあとに、マニュアルが「再確認してもらう」付きで改訂された
- **途中**：一部のステップだけチェックしている
- **未着手**：まだチェックしていない

## Notionから取り込んだマニュアル

院内Wiki（Notion）の **マニュアルDB** と **アシスト業務** にあったマニュアルを、2026年10月6日にこのアプリの形式へ変換して、初期データにしました。

- 件数：**82件**（受付・会計 33／診療補助 23／衛生士業務 11／滅菌・消毒 5／開院・閉院 3／カルテ・用語 3／院内ルール・申請 3／器具・材料 1）
- これに、Notionに無かった緊急時対応のサンプル2件（気分不良・針刺し事故）を加えた **84件** が初期データです。
- 原本は `data/notion-manuals.json`。`node data/validate.js` で形のチェックができます。

| Notion | アプリ |
| --- | --- |
| 受付業務ＤＢ | 受付・会計（朝の準備・昼前後・締作業は「開院・閉院」、受付の在庫管理は「器具・材料」） |
| 衛生マニュアルDB | 衛生士業務（新しいカテゴリ） |
| 滅菌・消毒・掃除DB | 滅菌・消毒 |
| アポの取り方DB・カルテの書き方DB・カルテ用語DB | カルテ・用語（新しいカテゴリ。カルテ用語36語は「カルテ用語集」1件にまとめました） |
| 申請書類DB | 院内ルール・申請 |
| アシスト業務（保険・自費・その他・外科の各ページ） | 診療補助（キーワードに「保険」「自費」「外科」などを付けています。インプラントは「キット」「オペ」「２次オペ」の3件） |

変換のしかた
- 太字の見出し・番号・箇条書きの1項目を「1ステップ」にしました。大きな見出しは、ステップの上に「区切り見出し」として表示します。
- 黄色や青の吹き出しのセリフは **声かけ例**、`★POINT` などは **ポイント**、`⚠️` や赤字は **注意** として表示します。
- 文章は要約せず、Notionの文言をそのまま使っています（明らかな誤字だけ直しました：「処方薬いついて」→「処方薬について」、「サワシリリン」→「サワシリン」、「原薄」→「原簿」）。
- 各マニュアルに「Notionの元ページ」へのリンクがあります（Notionにログインできる人だけ開けます）。
- 本文中のPCのログイン番号・端末のID/パスワードなどは、Notionのとおり残しています。番号を変えたときはマニュアルも直してください。

画像について
- 手順の画像（toothtooth-manual.jp に置かれているもの）は、アプリの中で表示され、タップで拡大できます。
- 画像を読み込めない環境（オフラインなど）では「画像はNotionの元ページで見られます」と表示されます。
- Notionに直接アップロードされていた画像（「カルテの書き方」の記入例）とWordの添付ファイル（「新入社員提出書類」）は、期限つきのURLしかないため、元ページで見る案内にしています。

取り込まなかったページ
- 「公費や書類について」… 「患者さんが提出される公費や書類について」と同じ内容のため1件にまとめました。
- 「SHININGの使い方」… 本文が空でした。
- 「滅菌」「消毒」… 子ページへのリンクだけのページでした（中身の「ハンドピースの滅菌」「オートクレーブの使い方」「超音波洗浄について」は取り込み済み）。
- アシスト業務の「印象」「iTero印象」「抜歯」… 本文が空でした。
- 「インプラント」… 子ページへのリンクだけのページでした（中の3ページは取り込み済み）。「インプラント使用器具について」は「インプラントキット」と同じ内容のため1件にまとめました。
- 新人衛生マニュアル・新人研修などは、今回は対象外です。

スプレッドシート版を **すでに設置している場合** は、管理者ページ →「スタッフ管理」→「マニュアルのデータ」の **「まだ無いマニュアルを追加」** で、新しく取り込んだ分だけを足せます（今あるマニュアルや編集した内容はそのまま）。全部を初期データに置き換えたいときは「初期データ（Notion取り込み）に戻す」を使います。新しく設置する場合は、初回に自動で登録されます。

## スタッフが辞めるとき（利用停止）

管理者ページ →「スタッフ管理」→ その人の「管理」→「退職にする（利用を停止）」を2回押します。

- その人のログインコードは、すぐに使えなくなります。
- その人がログインしていた端末は、次に操作したとき、または開いたままでも2分ほどで画面の中身が消え、ログイン画面に戻ります。
- これまでの進み具合の記録は残ります（集計からは外れます）。「再登録」すると新しいコードで戻せます。
- 退職した人が**管理者や編集ロックの暗証番号**を知っていた場合は、同じ画面で変更してください。管理者の暗証番号を変えると、ほかの端末で開いている管理者ページも閉じられます。
- ログインコードを人に教えていた心配があるときは「全員の端末をログアウト」を押し、必要ならコードを再発行します。

あわせて、医院の共用端末のパスコードや、共用のGoogleアカウントのパスワードも見直してください。
もっと念を入れるときは、Apps Script で「新しいデプロイ」を作ってURLを変え、古いデプロイを「アーカイブ」します（スタッフには新しいURLを配り直します）。

## スプレッドシート版の設置手順

1. https://script.google.com/ で「新しいプロジェクト」を作成し、名前を `みらい歯科 院内マニュアル` にします。
2. このフォルダのファイルをプロジェクトにコピーします。
   - `Code.gs` → 最初からある `コード.gs` に中身を貼り付け
   - `index.html` → 「＋」→「HTML」で `index` という名前のファイルを作り、中身を貼り付け
   - `appsscript.json` → 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにして、中身を貼り付け
   - （clasp を使う場合は、`.clasp.json` の `scriptId` を書き換えて、このフォルダで `clasp push`）
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：下の「公開範囲」を参照
4. 「デプロイ」を押し、表示された権限を許可します。
5. 表示されたウェブアプリのURLを開くと、データ用のスプレッドシート「みらい歯科 院内マニュアル データ」が自動で作られ、サンプルのマニュアルが登録されます。
6. ログイン画面の「管理者の方はこちら」から管理者の暗証番号を決め、「スタッフ管理」でスタッフを登録します。登録すると6桁のログインコードが表示されるので、本人に伝えます（あとから表示はできません。忘れたら再発行）。
7. スタッフの端末（スマートフォン・タブレット）でURLを開き、ホーム画面に追加してもらいます。ログインコードでログインします。

`index.html` や `Code.gs` を直したときは、「デプロイを管理」→ 編集 →「バージョン：新バージョン」で更新します（URLは変わりません）。

### 公開範囲（アクセスできるユーザー）

- **Googleアカウントを持つ全員**（`appsscript.json` の初期設定）：Googleにログインしている人がURLを開けます。医院の共用Googleアカウントでログインした端末で使う場合におすすめです。
- **全員**：ログインしなくても開けます。URLを知っている人なら誰でも開けるので、URLは院内だけで共有してください。
- Google Workspace をお使いなら、医院のドメイン内だけに限定することもできます。

## セキュリティのしくみ

- 何を見るにもログインが必要です。サーバー（`Code.gs`）は、毎回ログインの有効性を確かめてからデータを返します。
- 退職・コード再発行・ログアウトの操作をすると、その人の端末のログインはサーバー側ですぐに無効になります。
- スタッフには自分の進み具合だけが送られます。全員分を見られるのは管理者だけです。
- ログインコード・暗証番号・ログイン情報は、スプレッドシートやスクリプトプロパティに、元に戻せない形（ハッシュ値）で保存します。
- ログインに10分間で20回失敗すると、10分間ログインできなくなります（総当たり対策）。
- 120日使っていない端末は自動でログアウトされます。管理者ページは12時間で閉じます。
- データ用のスプレッドシートは、設置した人のGoogleドライブにあります。ほかの人と共有しないでください。

## 暗証番号とデータについて

- 管理者の暗証番号を忘れたときは、Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」で `ADMIN_PIN` を削除すると、次回に設定し直せます。
- 患者さまの個人情報は入力しないでください。
- お気に入り・最近見たマニュアル・文字の大きさは、端末ごとに保存されます。
- 初期データはNotionから取り込んだマニュアルです。緊急時対応の2件だけはサンプルなので、院内の手順・AEDの場所などに合わせて編集してください。
- 以前の版（ログインコードがない版）を設置済みの場合は、スタッフ管理でスタッフを登録し直してください。
