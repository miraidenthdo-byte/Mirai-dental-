# 院内マニュアルアプリ　はじめにお読みください

スタッフ向けの院内マニュアルを、スマートフォンやタブレットで見られるアプリです。
Google のサービス（Apps Script・スプレッドシート・ドライブ）だけで動くので、費用はかかりません。

## できること

- マニュアルをカテゴリ別に表示（受付・会計／診療補助／衛生士業務／滅菌・消毒／緊急時対応 など）。82件のマニュアルが最初から入っています
- その場で書き換え・追加・削除（うっかり編集しないよう「編集ロック」付き）
- 画像・動画の追加
- スタッフごとに6桁のログインコードを発行。だれがどのマニュアルまで読んだか、管理者が確認できます
- 退職したスタッフは、管理者ページの「利用を停止」ですぐに見られなくなります
- マニュアルが変わったら Slack に通知（使わなくてもOK）

## 設置のしかた（20分ほど）

医院の Google アカウントでログインしたパソコンで行います。

### 1. コピーを作る
1. 受け取ったリンクを開きます（Apps Script の画面が開きます）。
2. 左側の「ⓘ（概要）」を押し、右上の「**コピーを作成**」（四角が2つ重なったマーク）を押します。
3. 自分用のコピーが開きます。左上の名前を「〇〇歯科 院内マニュアル」などに変えておきます。

### 2. アプリとして公開する
1. 右上の「**デプロイ**」→「**新しいデプロイ**」を押します。
2. 「種類の選択」の横の ⚙️ を押し、「**ウェブアプリ**」を選びます。
3. 次のように設定します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「**デプロイ**」を押します。権限の確認が出たら、自分のアカウントを選んで許可します。
   （「このアプリは Google で確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」→「許可」）
5. 「ウェブアプリ」の下に出る、**最後が `/exec` で終わるURL**をコピーします。これがアプリのURLです。
   ※「ライブラリ」のURL（`/macros/library/…`）ではありません。

### 3. 最初の設定
1. コピーしたURLをブラウザで開きます。ピンク色のログイン画面が出ます。
2. 「**管理者の方はこちら**」を押し、管理者用の**4桁の暗証番号**を決めます（忘れないよう保管してください）。
3. 管理者ページの「**スタッフ管理**」タブで：
   - 「**医院名**」に自分の医院の名前を入れて保存します。
   - スタッフの名前を入れて「**追加してコードを発行**」。表示された6桁のコードを本人に伝えます（閉じると再表示できません。忘れたら「ログインコードを再発行」）。
   - 必要なら「**編集ロックの暗証番号**」も決めます。

### 4. スタッフのスマホに入れる
- アプリのURLを、スタッフに伝えます。
- **iPhone は Safari、Android は Chrome** で開いてもらい、共有メニューから「**ホーム画面に追加**」してもらいます。
  （LINE の中で開くと「現在、ファイルを開くことができません」と出ることがあります）
- 6桁のログインコードでログインします。

## 最初に直してほしいところ

入っているマニュアルは、別の医院で使っていたものです。次の部分は、自分の医院に合わせて書き換えてください（各マニュアルの「編集」から直せます）。

- 「〇〇歯科」「〇〇先生」となっている部分（電話対応、iTero の使い方、矯正相談 など）
- PC のログイン番号、クレジット端末やiTeroのID・パスワードの部分（「院内で確認してください」と書いてあります）
- 使っているシステムや業者の名前、院内ルール（有給申請など）

## Slack に通知したいとき（任意）

1. https://api.slack.com/apps で「Create New App」→「From scratch」でアプリを作ります。
2. 「Incoming Webhooks」をオンにし、「Add New Webhook to Workspace」で通知先のチャンネルを選びます（院内の人だけの非公開チャンネルがおすすめ）。
3. 表示された `https://hooks.slack.com/services/…` のURLをコピーします。
4. Apps Script の画面で、上の関数の選択欄から `authorize` を選んで「実行」し、許可します。
5. アプリの管理者ページ →「スタッフ管理」→「Slack通知」にURLを貼り付けて「登録する」→「テスト送信」。

## データの保存場所

設置すると、Google ドライブに次の2つが自動で作られます。**どちらも共有しないでください。**

- 「院内マニュアル データ」（スプレッドシート）：マニュアル・スタッフ・進み具合
- 「（医院名） 院内マニュアル 画像・動画」（フォルダ）：アプリで追加した画像と動画

## 困ったとき

- 画面が真っ白／エラーが出る：Apps Script の「デプロイを管理」→ ✏️ →「新バージョン」→「デプロイ」で更新し、もう一度開いてください。
- スタッフがコードを忘れた：管理者ページ →「スタッフ管理」→ その人の「管理」→「ログインコードを再発行」
- スタッフが辞めた：同じ画面で「利用を停止」
