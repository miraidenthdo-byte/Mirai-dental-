# 自費患者管理アプリ セットアップ手順

インプラント・矯正・自費補綴の患者を管理する Web アプリです。
Google Apps Script（GAS）で動作し、データはクリニックの Google アカウント内の
スプレッドシートに保存されます（外部サービスには送信されません）。

## できること

| 機能 | 内容 |
|------|------|
| ダッシュボード | 区分別の進行中人数・契約総額、今月の入金、未収金合計 |
| 要対応リスト | 次回予約が未設定／未収金あり／保証期限が近い（90日以内）／リコール対象（メンテ・保定中で180日以上来院なし）／相談後フォロー（相談から30日以上未契約） |
| 患者一覧 | 氏名・フリガナ（ひらがな可）・カルテ番号・電話番号で検索、区分・ステータスで絞り込み、並べ替え、CSV出力 |
| 患者詳細 | 1人の患者に複数の治療を登録可能（例: インプラント＋自費補綴） |
| 治療ごとの記録 | ステータス、部位、担当医、各種日付、契約金額、支払方法、保証期限、メモ |
| 区分ごとの項目 | インプラント: システム・本数・一次/二次手術日・上部構造装着日<br>矯正: 装置・保定開始日・調整料<br>自費補綴: 補綴物の種類・材料・セット日 |
| 入金管理 | 入金を記録すると入金済額・未収金・進捗バーを自動計算 |

ステータス: 相談中 → 検査・診断 → 治療中 → 保定・経過観察 → メンテナンス → 完了（または 中断）

---

## Step 1: GAS プロジェクトを作成する

1. https://script.google.com/ にアクセス（クリニックの Google アカウントで）
2. 「新しいプロジェクト」→ プロジェクト名を `Mirai-Dental-自費患者管理` に変更
3. `src/` の内容をコピーする

| GAS のファイル | 内容 |
|--------------|------|
| `コード.gs`（`Code.gs`） | `src/Code.gs` の内容に置き換え |
| `Index`（HTML）| 「＋」→「HTML」で `Index` という名前で作成し、`src/Index.html` の内容を貼り付け |
| `appsscript.json` | 「プロジェクトの設定」→「appsscript.json をエディタで表示」を有効にし、`src/appsscript.json` に置き換え |

> clasp を使う場合は `patient-manager/.clasp.json` の `scriptId` を書き換えて
> `patient-manager` ディレクトリで `clasp push` してください。

## Step 2: データ用スプレッドシートを作成する

1. GAS エディタで関数 `setup` を選択して「実行」
2. 権限の確認が出たら許可する
3. 実行ログに表示される URL が保存先スプレッドシート（「Mirai Dental 自費患者データ」）です
   - シート「患者」「治療」「入金」が作成されます
   - ID はスクリプトプロパティ `SPREADSHEET_ID` に自動保存されます

## Step 3: Web アプリとしてデプロイする

1. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 設定:
   - **次のユーザーとして実行**: `ウェブアプリにアクセスしているユーザー`
   - **アクセスできるユーザー**: `Google アカウントを持つ全員`
3. 「デプロイ」→ 表示された URL をブックマーク

## Step 4: スタッフに利用権限を付与する（重要）

このアプリは「アクセスしているユーザー」として実行されるため、
**スプレッドシートの編集権限を持つ人だけ**がデータを閲覧・編集できます。

1. Step 2 のスプレッドシートを開き「共有」
2. 利用するスタッフの Google アカウントを **編集者** として追加
3. スタッフには Web アプリの URL を共有する
   - URL を知っていても、スプレッドシートの権限がない人はデータを見られません
   - 初回アクセス時、各スタッフに権限の確認画面が出るので許可してもらう

> 患者の個人情報を扱うため、スプレッドシートは「リンクを知っている全員」で共有しないでください。
> 退職者が出た場合はスプレッドシートの共有から削除してください。

## 補足

- **更新履歴**: 各行に「更新日時」「更新者（メールアドレス）」が自動で記録されます
- **バックアップ**: スプレッドシートの「ファイル」→「変更履歴」で過去の状態に戻せます
- **アラートの日数を変えたい**: `Index.html` の `ALERT_DAYS`（保証期限・リコール・相談フォロー）を編集
- **選択肢を変えたい**: `Index.html` の `ORTHO_APPLIANCES`・`PROSTH_TYPES`・`MATERIALS`・`PAYMENT_METHODS` を編集
- **画面の確認だけしたい**: `src/Index.html` をブラウザで直接開くとデモモード（サンプルデータ、ブラウザ内にのみ保存）で動作します
- **既存データの取り込み**: スプレッドシートの各シートに直接貼り付けても構いません（ID 列は空にせず一意の値を入れてください。日付は `2026-04-01` 形式）
