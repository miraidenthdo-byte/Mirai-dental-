# みらい歯科 院内マニュアルアプリ

パステルピンクを基調にした、スタッフ向けの院内マニュアルアプリです。
スタッフごとの進み具合を記録し、管理者がまとめて確認できます。

## 2つの使い方

| | 体験モード | スプレッドシート版（スタッフ全員で使う） |
| --- | --- | --- |
| 開き方 | `index.html` をブラウザで開く | Google Apps Script のウェブアプリURLを開く |
| データの保存先 | その端末のブラウザの中だけ | Googleスプレッドシート（全員で共有） |
| スタッフ・進み具合 | サンプルが入っています | 管理者が登録したスタッフの実際の記録 |

同じ `index.html` が、開き方によって自動で切り替わります。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| カテゴリ別一覧・検索 | タイトル・手順・ポイント・キーワードをまとめて検索 |
| ステップチェック | 手順ごとにチェック。全部チェックすると「完了」として記録 |
| 使っている人の切り替え | 右上の名前ボタンから。共用の端末でも人ごとに記録できます |
| あなたの進み具合 | ホームとくわしい画面で、自分の完了率・要再確認を確認 |
| その場で編集＋ロック | 「ロックを解除して編集」→ 書き換え →「保存してロック」 |
| 再確認の依頼 | 編集時に「スタッフ全員に再確認してもらう」を選ぶと、完了済みの人が「要再確認」になります |
| 管理者ページ | スタッフ別・マニュアル別の進み具合、スタッフ登録、暗証番号、データ管理 |

## 管理者ページ

設定（右上の歯車）→「管理者ページを開く」。初回に管理者用の4桁の暗証番号を決めます。

- **スタッフ別**：全体の完了率、要再確認の件数、この7日間の完了数。スタッフを完了率の低い順に表示し、押すとその人のマニュアルごとの状況（完了日・途中のステップ数）が見られます。
- **マニュアル別**：完了した人が少ない順に表示。押すと、誰が完了／途中／未着手かが分かります。
- **登録・設定**：スタッフの追加・名前の変更・削除、編集ロックの暗証番号、管理者の暗証番号、マニュアルの書き出し／読み込み。

進み具合の表示は次の4つです。

- **完了**：すべてのステップにチェックした（チェックをリセットしても完了の記録は残ります）
- **要再確認**：完了したあとに、マニュアルが「再確認してもらう」付きで改訂された
- **途中**：一部のステップだけチェックしている
- **未着手**：まだチェックしていない

## スプレッドシート版の設置手順

1. https://script.google.com/ で「新しいプロジェクト」を作成し、名前を `みらい歯科 院内マニュアル` にします。
2. このフォルダのファイルをプロジェクトにコピーします。
   - `Code.gs` → 最初からある `コード.gs` に中身を貼り付け
   - `index.html` → 「＋」→「HTML」で `index` という名前のファイルを作り、中身を貼り付け
   - `appsscript.json` → 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにして、中身を貼り付け
   - （clasp を使う場合は、`.clasp.json` の `scriptId` を書き換えて、このフォルダで `clasp push`）
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：下の「公開範囲」を参照
4. 「デプロイ」を押し、表示された権限を許可します。
5. 表示されたウェブアプリのURLを開くと、データ用のスプレッドシート「みらい歯科 院内マニュアル データ」が自動で作られ、サンプルのマニュアルが登録されます。
6. 管理者ページでスタッフを登録します。
7. スタッフの端末（スマートフォン・タブレット）でURLを開き、ホーム画面に追加してもらいます。初回に自分の名前を選びます。

`index.html` や `Code.gs` を直したときは、「デプロイを管理」→ 編集 →「バージョン：新バージョン」で更新します（URLは変わりません）。

### 公開範囲（アクセスできるユーザー）

- **Googleアカウントを持つ全員**（`appsscript.json` の初期設定）：Googleにログインしている人がURLを開けます。医院の共用Googleアカウントでログインした端末で使う場合におすすめです。
- **全員**：ログインしなくても開けます。URLを知っている人なら誰でも開けるので、URLは院内だけで共有してください。
- Google Workspace をお使いなら、医院のドメイン内だけに限定することもできます。

## 暗証番号とデータについて

- 暗証番号（管理者・編集ロック）は、うっかり操作を防ぐためのものです。スプレッドシート版では、Apps Script のスクリプトプロパティに保存されます。
- 管理者の暗証番号を忘れたときは、Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」で `ADMIN_PIN` を削除すると、次回に設定し直せます。
- 進み具合はスタッフ全員から見える院内向けのデータです。患者さまの個人情報は入力しないでください。
- お気に入り・最近見たマニュアル・文字の大きさ・「使っている人」は、端末ごとに保存されます。
- 最初のマニュアルはサンプルです。院内の手順・AEDの場所などに合わせて編集してください。
