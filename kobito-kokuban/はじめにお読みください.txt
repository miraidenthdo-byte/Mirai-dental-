  こびとのこくばん　〜 待合室用・タッチであそぶ黒板 〜
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

黒板にチョークで線を描くと、小さなこびとたちがその上を歩いたり、
すべり台のようにすべったり、ジャンプして乗ったりします。
インターネット接続もインストールも不要です。


■ 使い方（かんたん）
────────────────────
1. この「kobito-kokuban」フォルダをまるごとパソコンにコピーします
   （例：デスクトップや C:\kobito-kokuban など）
2. 「start.bat」をダブルクリック
   → 全画面で起動します

  ※「WindowsによってPCが保護されました」と出た場合は
    「詳細情報」→「実行」を押してください（初回のみ）。
  ※ start.bat が使えない場合は「index.html」をダブルクリックし、
    画面を一度タッチすると全画面になります（F11キーでも可）。


■ 終了のしかた
────────────────────
キーボードで「Alt」+「F4」を押します。


■ パソコンの電源を入れたら自動で起動させたい場合
────────────────────
「autostart-on.bat」をダブルクリック → 次回から自動で起動します。
やめたいときは「autostart-off.bat」をダブルクリック。

※ フォルダを別の場所に移動した場合は、もう一度 autostart-on.bat を実行してください。


■ あそびかた
────────────────────
・下のチョークをタッチすると色を選べます（白・黄・ピンク・青・緑・オレンジ）
・黒板を指でなぞると線が描けます（何人でも同時に描けます）
    - ゆるやかな線 … こびとが歩きます
    - ななめの線   … すべり台になります
    - 縦の線       … 壁になって、こびとがひき返します
    - 頭の上の線   … こびとがジャンプして乗ってきます
・こびとをタッチ … ジャンプしてよろこびます
・こびとを長押ししてドラッグ … つまんで運べます（はなすと落ちます）
・黒板をトンとタッチ … キラキラ星が出ます
・「けす」（黒板消し）を選んでなぞる … 線を消せます


■ 自動でおこること（スタッフの手間なし）
────────────────────
・描いた線は約90秒でゆっくり消えます
・だれも触らないと1分でこびとが眠り、3分で黒板がきれいになります
・タッチするとこびとが目をさまします


■ スタッフ用キーボード操作
────────────────────
  C … 黒板をきれいにする
  M … 効果音 オン／オフ
  F … 全画面 オン／オフ
  + … こびとを1人ふやす
  - … こびとを1人へらす


■ 設定の変更（必要なときだけ）
────────────────────
「index.html」をメモ帳で開くと、上のほうに「設定」があります。
数字を書きかえて保存すると反映されます。

  kobitoCount   こびとの人数（初期値 10）
  lineLifeSec   線が消え始めるまでの秒数（初期値 90）
  sound         効果音 true=あり / false=なし
  volume        音量 0〜1（初期値 0.5）
  sleepAfterSec こびとが眠るまでの秒数（初期値 60）
  idleClearSec  黒板を自動でけすまでの秒数（初期値 180）


■ 院内で使うときのおすすめ設定（Windows）
────────────────────
・画面が消えないように：
  設定 → システム → 電源 → 「画面の電源を切る」「スリープ」を「なし」に
・画面の端からスワイプしたときのメニューが気になる場合：
  タッチパネルの端は避けて設置するか、Windowsの「タッチジェスチャ」をオフにしてください
  （設定 → Bluetoothとデバイス → タッチ → 3本指・4本指のタッチジェスチャ をオフ）
・お子さまが触る画面なので、定期的にアルコールで画面を拭いてください。


■ 動作環境
────────────────────
Windows 10 / 11（Google Chrome または Microsoft Edge）
※ Edge は Windows に標準で入っているので、追加のインストールは不要です。
Mac の場合は index.html を Chrome または Safari で開いて全画面にしてください。
