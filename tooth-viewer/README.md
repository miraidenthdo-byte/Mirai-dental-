# 歯牙・根管 3Dビューア

歯科用CT（CBCT）の DICOM を読み込み、選択した歯だけを抽出して、歯牙形態・根管形態を色分けした 3D ボリュームレンダリング（VR）で表示する Web アプリです。

- **Google Chrome で `index.html` を開くだけで動きます**（インストール・サーバー不要、オフライン可）
- 画像はブラウザ内だけで処理され、外部に送信されません

## 使い方

1. 「📁 フォルダを開く」で DICOM フォルダを選択（ドラッグ＆ドロップも可）。試すだけなら「🧪 デモデータ」
2. アキシャル／コロナル／サジタル断面で、抽出したい歯の象牙質をクリック → 黄色い枠（ROI）が表示されます
   - 歯番（FDI）を選ぶと ROI の大きさ・上下方向（上顎／下顎）を自動調整
3. クリックすると自動でしきい値が決まり、3D表示されます
4. **歯軸の傾き**：コロナル・サジタル断面の黄色い歯軸線の端（●）をドラッグするか、「傾き」スライダーで抽出枠を歯軸に合わせます。
   「🎯 歯軸を自動で合わせる」で、抽出した歯の主軸に枠の傾き・中心・長さを自動で合わせて再抽出します
   （15°傾いた歯で 15.5° と推定、根管Dice 0.935 → 0.964 に改善）

## 抽出範囲の指定（自由度）

- 枠の各面の **■ をドラッグ**：その面だけを伸縮（左右・前後・上下を片側ずつ）
- 歯軸線の端の **● をドラッグ**／「傾き」スライダー：枠を歯軸に合わせて傾ける
- **🖌 除外ブラシ**：断面上でなぞった部分（くっついた骨・隣在歯など）を抽出対象から外す（「1つ戻す」「全消去」可）
- 周囲の骨は表示しません（歯だけを表示）
- 骨が歯根に密着している場合は、骨と象牙質の濃度差で自動的に分離します

## 3D表示

- 歯は半透明（輪郭ほど濃く表示）、根管は不透明の緑で表示（「配色：赤の根管」に切替可）
- プリセット：不透明 / 根管を透視 / 根管のみ、「高さで色分け」で根管の走行を虹色表示
- 断面カット（X・Y・Z）、自動回転、正面・側面・歯冠側・根尖側ビュー、方向表示（A/P・R/L・S/I）
- 📷 画像保存、🧊 **STL出力**（歯・根管、DICOM患者座標・mm単位）
- 📏 断面上の2点間距離計測
- 計測：歯の高さ、各組織の体積、高さごとの根管数グラフ（Vertucci分類の目安）

## 抽出の仕組み

1. ROI 内を平滑化し、しきい値で硬組織を二値化
2. 収縮（骨との分離）→ クリック点から領域拡張 → 元の形に復元
3. 距離変換＋マーカー付きウォーターシェッドで隣在歯との接触部を分離（隣在歯全体を競合させる）
4. **断面ごとの追跡（骨との分離）**：実際のCBCTでは皮質骨と歯根象牙質の濃さがほぼ同じで、しきい値だけでは骨へ漏れる。
   そこで骨のない歯冠の最大豊隆部から根尖側へ1断面ずつ追跡し、前の断面の輪郭から外へ広がれるのは1画素まで、
   しかも「前の断面では暗かった（歯根膜・歯髄だった）」「外側が軟組織」「厚い骨の内部に接していない」ときだけに限る。
   水平な歯根膜（根分岐部の天井）・断面内の細い谷（歯根膜）も検出して、骨が上下に続いている所から入り込まないようにする
5. **枠の自動調整**：歯をクリックした直後の1回だけ、歯冠の広がり＋周囲2.5mmに合わせて枠の中心と幅を直す（歯根の切れ防止）
6. **高精度ステージ**：歯の周囲だけを 0.07mm 前後に三線形補間し、
   - 歯の外形・歯髄の表面：ノイズでざらつかないよう、ならしたCT値の等値面で作る（サブボクセル精度）
   - 根管：ブラックトップハット＋ヒステリシス閾値に加え、**根管の中心線追跡**
     （歯軸方向にならした画像で、歯根断面の中の「周囲の象牙質より暗い局所最小」を断面ごとに拾い、上下につながる1.5mm以上の点列を根管とする）
     で、写りの薄い細い根管も途切れず根尖近くまで描く
   - 根管の殻判定（根分岐部の骨髄腔の誤検出を除く）は、同じ高さの象牙質の濃さと比べる（歯根は歯冠より暗く写るため）
7. エナメル質しきい値で エナメル質／象牙質 を区別

## 精度検証（合成ファントム、`node test/accuracy-test.js`）

正解ラベルのある合成ファントム（撮影系のぼけ・ノイズ入り）で測定した結果：

| 条件 | 歯 Dice | 根管 Dice | 根管 再現率 | 根管 適合率 | 断面ごとの根管数一致 |
|---|---|---|---|---|---|
| 第一大臼歯 0.15mm | 0.984 | 0.965 | 0.993 | 0.938 | 76% |
| 小臼歯（2根管→合流）0.15mm | 0.986 | 0.956 | 0.992 | 0.923 | 96% |
| 単根歯（側枝あり）0.15mm | 0.984 | 0.955 | 0.982 | 0.930 | 97% |
| 第一大臼歯 0.10mm | 0.988 | 0.975 | 0.999 | 0.952 | 86% |
| 第一大臼歯 0.20mm 高ノイズ | 0.981 | 0.954 | 0.971 | 0.939 | 73% |
| 第一大臼歯 0.25mm | 0.981 | 0.956 | 0.975 | 0.937 | 72% |
| 第一大臼歯 15°傾斜＋歯軸自動合わせ | 0.971 | 0.954 | 0.973 | 0.936 | 74% |
| 第一大臼歯 骨が歯根に密着（歯根膜腔なし） | 0.975 | 0.918 | 0.968 | 0.873 | 70% |

- 大臼歯の根管数の不一致は主に ①根尖から約0.5〜0.7mm以内 ②髄床底で根管口と髄腔の間の象牙質が0.1〜0.3mm（解像度以下）の部分
- 0.2mm 以上の粗いボクセルでは、直径0.3〜0.5mm程度の細い根管が途切れることがあります。根管治療目的では **0.1〜0.15mm 以下の小照射野CBCT** を推奨

## 実データでの確認（検証用CBCT、下顎左側第一大臼歯 #36、0.19mm）

- 従来法では舌側・頬側の皮質骨へ大きく漏れ、近心根の根管が途中で途切れていた
- 断面追跡・中心線追跡により、近心根（MB・ML）・遠心根の根管が根尖付近まで連続して描出され、骨への漏れも大きく減少
- 残る課題：歯根が舌側皮質骨に歯根膜腔なしで接している部分では、骨の一部が帯状に残ることがある（除外ブラシで消せます）
- 臨床使用の前に既知症例で確認してください

## 対応形式

- 非圧縮 DICOM（Implicit / Explicit VR Little Endian）、スライス分割形式・マルチフレーム（Enhanced CT）
- JPEG Baseline（8bit）
- JPEG Lossless / JPEG 2000 などの圧縮形式は非対応です。撮影ソフトから「非圧縮」で書き出してください
- 大容量データ（約2.6億ボクセル超）は自動で間引いて読み込みます
